# Glossary & Definitions

This page defines key terms and acronyms used in the GradMap project. Expand this list as new terminology is introduced.

| Term | Definition |
| --- | --- |
| **Degree Plan** | A structured sequence of courses required to complete a degree. |
| **Course Catalog** | A list of available courses with descriptions, prerequisites and credit values. |
| **GPA** | Grade Point Average, a numerical representation of a student’s academic performance. |
| **Advisor** | A faculty member who assists students in planning and approving their degree plans. |
| **Admin** | A user with permissions to manage users, courses and system settings. |
| **Prerequisite** | A course that must be completed before enrolling in a specific course. |
| **Plan of Study** | A customized timeline showing when a student plans to take each course. |
