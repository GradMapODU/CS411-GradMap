# GradMap User Manual

Welcome to the GradMap User Manual. GradMap is a web‑based system designed to help students plan and track their progress toward graduation. The application allows students to build degree plans, schedule courses, and monitor completion status, while providing advisors and administrators with tools to manage course offerings and support students. This manual is part of CS 411W Lab 3 and defines the structure of the documentation. Detailed instructions will be added in Lab 4.
